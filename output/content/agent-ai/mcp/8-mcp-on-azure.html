Azure stack

There are now two different “Azure + MCP” stories

Use Azure MCP Server when agents need standardized tools to operate Azure resources. Build your own remote MCP server when you need to expose private business systems, APIs or data products to agents.

Azure MCP Server

Microsoft-provided MCP server for interacting with Azure resources. It can be used from MCP-compatible clients and agent frameworks.

Custom MCP server on Azure

Your server exposes internal capabilities. Microsoft Foundry documentation shows a pattern using Azure Functions, Azure API Center/tool catalogs, and Foundry Agent Service.

Agent integration

Microsoft Foundry Agent Service

Register custom MCP capabilities through the organizational tool catalog and connect them to agents.

Copilot Studio

Add remote MCP servers as tools; review tool names/descriptions, configure authentication and inspect activity traces before publishing.

Semantic Kernel / custom agents

Use MCP-compatible clients to access Azure MCP Server or your custom remote servers without bespoke tool integrations.

Azure KONTROLS

Production controls to add before broad rollout

Managed identity / Entra

Avoid shared long-lived secrets where managed identity and delegated access can be used.

Private networking

Keep sensitive backends private; expose only the MCP boundary required by clients.

Application Insights

Correlate agent, MCP, policy and downstream operations with business outcomes.

Catalog governance

Track owner, version, approval, scopes and lifecycle for every exposed capability.
