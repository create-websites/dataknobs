Quick reference
A production agent is a controlled workflow.

Use LangChain for the harness, LangGraph for durable control flow, and explicit policy/evaluation around both.

ScopeWorkflow
BuildHarness
ControlGraph + policy
OperateEval + trace

The 7-stage production path

1 · ScopeChoose a bounded workflow and define the result.
2 · SpecifyDocument inputs, outputs, tools, exceptions and approval points.
3 · HarnessBuild with create_agent for simple tool loops.
4 · PersistAdd checkpoints and thread state only when needed.
5 · ControlUse scopes, policy, middleware and human approval.
6 · EvaluateTest outcomes, tools, state, cost and safety.
7 · OperateObserve failures, regress changes and roll out gradually.

Core components in 2026

Model

Model + system policy

Interprets the task and chooses candidate actions; it should not own enterprise authorization.

Tools

Typed action surface

Functions, APIs and tool servers with explicit schemas, errors and permissions.

State

Messages + workflow state

Current thread state, checkpoints and optional long-term memory.

Graph

Control flow

Explicit routing, retries, interruptions and durable execution when simple loops are not enough.

Policy

Authority boundary

Deterministic rules and human approvals for high-impact actions.

Eval

Outcome evidence

Task success, tool behavior, latency, cost and safety regression testing.

Architecture choice

ApproachUse whenTrade-off
LangChain create_agentFocused agent with a straightforward tool loopFastest path, less explicit control flow
LangGraph workflowRouting, retries, persistence, approvals, long-running stateMore design work, much stronger control
Subagents / multi-agentSpecialization or context isolation creates clear valueMore coordination, cost and attribution complexity

Production rule

Do not deploy a prompt. Deploy a controlled workflow.

The deployable unit includes tool contracts, identity, state policy, evaluation suite, observability, timeouts, retries, approval gates and rollback: not only model instructions.

Frequently asked questions

Can I build production agents with LangChain only?

Yes for simpler workflows. LangChain create_agent is designed as a configurable harness. Use LangGraph when you need deeper orchestration and persistence control.

Is vector memory required?

No. Start with explicit thread state and add long-term memory only when the use case demonstrates value and you have retention, privacy and quality controls.
