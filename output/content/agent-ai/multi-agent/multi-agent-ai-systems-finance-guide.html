Finance architecture

Separate deterministic finance logic from probabilistic agent reasoning

Pricing, P&L, exposure, limits and accounting should remain deterministic services. Agents are strongest at research, synthesis, orchestration, exception handling and human-facing explanation.

Specialized team

Useful agent boundaries follow evidence, computation and authority

Research agent

Collects filings, earnings, macro releases, news and internal research with source provenance.

Quant agent

Invokes deterministic calculators and models for scenarios, factors, options and portfolio analytics.

Risk agent

Checks exposure, limits, concentration, liquidity and scenario breaches before recommendations progress.

Compliance agent

Applies policy, disclosure, suitability and communication requirements; flags cases needing review.

Orchestrator

Coordinates the specialists, resolves missing evidence and prepares a reviewable decision package.

High-stakes controls

Do not let the language model become the control plane

Trading authority
Keep execution permissions separate. Require deterministic pre-trade checks and explicit approval for material actions.
Data provenance
Store source, timestamp, version and transformation lineage for evidence used in decisions.
Auditability
Record prompts/policies, tool calls, calculations, approvals and final outputs with stable correlation IDs.
