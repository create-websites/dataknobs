The Composable Data Product Factory

Dataknobs is the missing control plane for Google Cloud. We productize "knobs"—secure, governed building blocks—to turn BigQuery and Vertex AI into a repeatable factory.

Core Concepts

Moving from bespoke pipelines to assembled products.

The "Knob"

A versioned, parameterized module that creates or updates an asset. It's not just code; it's a contract containing configuration, input/output definitions, security models, and observability hooks.

  • Config Schema (YAML/JSON)
  • Embedded Governance Hooks
  • Operational Defaults

The "Recipe"

A composition of knobs that forms a Data Product. Users build recipes by linking knobs in a dependency graph. The platform generates execution plans for Cloud Composer, Dataform, or Vertex AI.

The Data Product

The packaged outcome: Tables, Views, APIs, Embeddings, or Search Indexes. Delivered with comprehensive metadata, lineage, SLAs, and access rules attached.

knob_definition.yaml

name: customer_sentiment_enrichment
version: 1.2.0
type: ai_transformation
inputs:
  - source: raw_support_tickets
    schema: [ticket_id, content]
config:
  model: vertex_ai/gemini-1.5-pro
  prompt_template: "Summarize sentiment..."
governance:
  lineage: true
  pii_scan: required
outputs:
  - target: bq.enriched_tickets
    sla: "4h"

GCP Native Advantage

Governed AI Transformations

We leverage BigQuery's native AI SQL surface to keep data secure and governance intact. No more bespoke Python scripts running on unguarded laptops.

AI.GENERATE

Structured output generation. Transform text blobs into governed table schemas (entities, attributes, normalized keys) directly via SQL.

SELECT * FROM ML.GENERATE_TEXT...

Vector Search

Embed and Index knobs. Use AI.GENERATE_EMBEDDING to create vectors and manage indexes for RAG workflows directly in BigQuery.

VECTOR_SEARCH(query_embedding, ...)

Remote Models

Vertex AI governance wrapper. Call Gemini or custom models safely. Training and inference happen in Vertex, controlled by IAM.

CREATE MODEL ... REMOTE WITH CONNECTION
