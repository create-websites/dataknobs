Eight principles for reliable research agents

2026 refreshThe original principles remain useful, but modern research agents need stronger evidence discipline, tool trust, evaluation and bounded learning. The goal is not to expose “thinking”; it is to produce a reproducible evidence trail.
01

1. Start with a research contract

Define the question, audience, time window, acceptable sources, required depth, output format and what would count as uncertainty or insufficient evidence.

02

2. Decompose with bounded orchestration

Break the problem into explicit sub-questions and assign only the context and tools needed for each. Keep a visible task plan that can be inspected and revised.

03

3. Search broadly, then deepen

Map the source landscape first, then pursue primary and authoritative sources for claims that materially affect the conclusion.

04

4. Match tools to evidence type

Use web search for current public facts, retrieval for private corpora, code for calculations, databases for structured facts and deterministic validators for exact rules.

05

5. Separate fact, inference and uncertainty

Citations should support factual claims directly. Mark synthesized conclusions as analysis and surface meaningful uncertainty rather than flattening everything into confident prose.

06

6. Parallelize independent work

Run independent source searches or calculations concurrently to reduce latency, but serialize steps that rely on shared state, prior evidence or approval.

07

7. Evaluate before synthesis

Check source authority, freshness, contradictions, coverage and whether the evidence actually answers the question. Use claim-level verification for consequential findings.

08

8. Improve through controlled evaluation loops

Turn failures into versioned tests. Improve prompts, retrieval, tools, routing and policies through measured releases: not uncontrolled self-modification or memory accumulation.

A modern research workflow

FrameRestate the decision or question and define scope, freshness and evidence requirements.
PlanCreate sub-questions, dependencies and tool/source strategy.
ExploreSearch broadly enough to identify authoritative sources, terminology and competing explanations.
VerifyRetrieve primary sources, run calculations, resolve contradictions and capture citations.
SynthesizeAnswer the user’s actual question; distinguish fact from analysis and include uncertainty.
EvaluateScore completeness, citation support, freshness, consistency and usefulness; log failures for regression tests.

Frequently asked questions

Should a research agent expose chain-of-thought?

No. Good research quality comes from explicit plans, sources, evidence, calculations, tool traces, intermediate artifacts and uncertainty: not disclosure of hidden chain-of-thought.

When should research agents use parallel tools?

Parallelize independent searches or analyses. Keep dependent steps, shared-state updates, transactions and approval-sensitive operations ordered.

How should research agents improve over time?

Use versioned evaluation datasets, outcome feedback, error taxonomies and controlled updates to prompts, tools, retrieval and policies. Avoid unconstrained self-modification in production.
