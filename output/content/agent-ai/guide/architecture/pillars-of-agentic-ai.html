The other half is authority, state, evidence and evaluation.

From cognitive pillars to enterprise controls

The classical concepts still matter: perceive, remember, reason, act, reflect and collaborate. The change in 2026 is that each pillar now has a corresponding control surface that can be configured, measured and governed.

Perception / contextSource allowlists, trust labels, freshness, retrieval quality and privacy filters.
MemoryWrite policy, retention, provenance, user scope, deletion and rollback.
Reasoning / planningPlanner choice, decomposition depth, budget, retry count and termination criteria.
ActionTool schemas, identity, scopes, transaction limits, sandbox and approval gates.
Reflection / evaluationOutcome validators, critics, human review, regression tests and post-run scoring.
CollaborationDelegation policy, A2A trust, handoff contracts, shared state and attribution.
DataKnobs principle: every meaningful increase in agent capability should have a corresponding knob for authority, evidence and evaluation.

Patterns that sit on top of the pillars

Loop

Tool-use agent

Model selects a tool, observes the result and continues until the task is complete.

Workflow

Planner → executor

Separates decomposition from action so plans and execution can be evaluated independently.

Routing

Specialist router

Selects a model, tool, knowledge source or sub-agent based on task type and risk.

Quality

Generate → validate → repair

Runs explicit checks against schema, evidence or business rules before accepting an output.

Control

Human approval

Pauses before high-impact actions and resumes after an authorized decision.

Scale

Supervisor / subagents

Delegates bounded work to specialists while keeping shared outcome and control evidence.

What changed since the earlier generation of agent frameworks?

Earlier framing2026 production framing
Prompt + toolsHarness + typed tools + state + middleware/policy
Memory means chat historyThread state, checkpoints, durable stores and retention controls
Reasoning trace as observabilityObservable events, tool calls, state transitions, validations and outcomes
Multi-agent by defaultUse multiple agents only when specialization or isolation pays for complexity
Human-in-the-loop as UXApproval as an authorization and risk-control primitive

Frequently asked questions

Are ReAct and agentic AI the same thing?

No. ReAct is one reasoning-and-action pattern. Agentic AI is the broader system that combines models, context, tools, state, controls and evaluation.

Should production systems log chain-of-thought?

Production observability should focus on execution evidence such as inputs, tool calls, state transitions, policy decisions, validators and outcomes rather than hidden chain-of-thought.
