Lifecycle, not one-time build

Eight stages from opportunity to evolution

Modern agent delivery blends product management, software engineering, data, AI evaluation, security, and operations.

1

Opportunity

Business outcome, task boundaries, automation desirability.

2

Architecture

Workflow vs agent, state, tools, single vs multi-agent.

3

Context + tools

Data quality, RAG, APIs, MCP, schemas, permissions.

4

Prototype

Small task set, traces, failure taxonomy, baseline.

5

Evaluate

Task success, trajectory, safety, latency, cost.

6

Govern

Identity, policy, approvals, audit, red teaming.

7

Deploy

Canary rollout, durable state, observability, SLOs.

8

Evolve

Drift, tool changes, eval refresh, experiments.

Cross-functional delivery

The roles change as autonomy grows

A production agent is not solely an ML project. It is an operational system with authority and a changing behavior surface.

AI Product Owner

Owns business outcome, task boundary, UX, adoption, and escalation model.

Agent / Platform Engineer

Builds runtime, tools, state, orchestration, and integrations.

Domain + Data Expert

Defines ground truth, policy nuance, data quality, and difficult edge cases.

Security / Governance

Owns identity, permissions, red-team scenarios, compliance, and audit requirements.

Evaluation Engineer

Builds benchmark sets, graders, regression tests, and trajectory analysis.

AgentOps / SRE

Owns observability, SLOs, incidents, rollback, state, and production reliability.

Human Supervisor

Approves sensitive actions, reviews uncertain cases, and supplies corrective feedback.

FinOps / Business Ops

Tracks cost per successful task, value delivered, and capacity economics.

Production gates

Do not ship on “the demo looks good”

Each stage should have an evidence-based exit gate.

GateEvidenceExamples
ValueBusiness task is worth automating or augmentingTime saved, throughput, service quality, revenue, risk reduction
CapabilityAgent succeeds on representative tasksTask success rate, groundedness, tool-call correctness
SafetyControls constrain harmful or unauthorized behaviorAttack success rate, policy adherence, approval coverage
OperationsSystem can fail safely and recoverRetries, timeouts, idempotency, resumption, incident playbooks
EconomicsCost and latency fit the value of the taskCost per successful task, p95 duration, human review load
