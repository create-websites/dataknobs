Threat model update

MCP security is more than input sanitization

The dangerous boundary is not only the MCP server code. It is the combination of tool metadata, runtime context, credentials, agent trust, downstream systems, and supply chain.

Tool / prompt poisoning

Malicious tool descriptions or results can manipulate the agent into taking actions outside the user’s intent.

Supply-chain compromise

An approved MCP server or package can change behavior later, turning an existing trust relationship into a runtime attack path.

Credential abuse

Over-privileged service credentials can let a compromised tool act far beyond the requested operation.

Data exfiltration

Tool calls can leak secrets through arguments, responses, logging, hidden recipients, outbound requests, or indirect prompt injection.

Confused deputy

An agent or server with broader privileges than the caller may be tricked into using authority on someone else’s behalf.

Long-running task abuse

Durable tasks need unguessable IDs, per-request authorization, caller binding, cancellation, and the same trust model as direct calls.

Layered defense

Controls should be deterministic where possible

Do not rely on the model to remember security policy. Enforce policy outside the model loop.

Identity + least privilege
Scoped credentials per agent/tool, short-lived tokens, issuer-bound auth, no token passthrough shortcuts.
Tool allowlists + schemas
Explicit tools, strict JSON schemas, validation, bounds, idempotency, and deny-by-default operations.
Approval gates
Human confirmation for deletion, money movement, production changes, external communications, or sensitive exports.
Network + data egress
Restrict destinations, redact secrets, inspect responses, and keep sandboxes from reaching unnecessary hosts.
Modern attack scenario

The server can become malicious after approval

A key 2026 lesson is runtime trust drift: a server can initially appear safe, then alter tool metadata or outputs to steer a trusted agent toward local secrets or privileged actions.
